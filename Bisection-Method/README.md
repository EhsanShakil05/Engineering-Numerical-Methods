# Bisection Method in MATLAB

## Objective

To numerically determine the root of a nonlinear equation using the Bisection Method.

## Problem Statement

f(x) = x³ − x − 2

Find the root of:

f(x) = 0

## Features

* Automatic interval detection within a specified search range
* Iterative root refinement
* User-defined tolerance
* Iteration tracking
* Graphical visualization of the root

## MATLAB Concepts Used

* Anonymous functions
* Loops
* Conditional statements
* Numerical methods
* Plotting and visualization

## Result

Approximate Root:

x ≈ 1.52138
