# Newton-Raphson Method in MATLAB

## Objective

To determine the root of a nonlinear equation using the Newton-Raphson Method.

## Problem Statement

f(x) = x³ − x − 2

Find the root of:

f(x) = 0

## Theory

The Newton-Raphson Method uses the iterative formula:

x(n+1) = x(n) − f(x(n))/f'(x(n))

where f'(x) is the derivative of the function.

## Features

* User-defined initial guess
* Iteration tracking
* Convergence checking
* Derivative validation
* Root visualization

## MATLAB Concepts Used

* Anonymous functions
* Loops
* Conditional statements
* Numerical methods
* Plotting

## Result

Approximate Root:

x ≈ 1.52138
