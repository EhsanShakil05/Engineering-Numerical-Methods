# Engineering Numerical Methods

A collection of MATLAB implementations of numerical methods commonly used in engineering analysis, scientific computing, and numerical problem-solving.

This repository documents the development, implementation, analysis, and comparison of fundamental root-finding algorithms used in engineering applications.

---

## Methods Included

### Root-Finding Methods

* ✅ Bisection Method
* ✅ Newton-Raphson Method
* ✅ Secant Method
* ✅ False Position Method (Regula Falsi)
* ✅ Fixed Point Iteration Method
